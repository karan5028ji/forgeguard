# Security Policy

## Supported Versions
| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability
We take the security of ForgeGuard and our autonomous remediation engine seriously.

If you discover a security vulnerability within ForgeGuard:
1. **Do not create a public GitHub issue.**
2. Email your findings directly to `security@swarmforge.ai` with:
   - Detailed description of the vulnerability.
   - Proof-of-concept (PoC) or minimal reproduction script.
   - Potential impact assessment.
3. Our security triage team will acknowledge receipt within 24 hours and provide an initial assessment within 48 hours.
